# 第 6A 讲：多头因果注意力

第五讲已经验收。本关只增加多头，残差、LayerNorm、FFN 留到 6B。

## 为什么需要多个头

单头注意力为每个 query 产生一套对前文位置的权重。这一套权重共同用于所有 value 通道。
但预测一个字符时，不同线索可能来自不同位置。多头允许模型在不同的特征子空间中，分别计算一套权重，再汇合结果。
各头学到什么由训练决定；它们没有预先分配好的“语法头”“语义头”等职责。

设输入 x 的形状为 (B,T,C)，头数 H，每头宽度 D=C/H。本题要求 C 能被 H 整除。
我们仍使用四个 C→C 的线性层，没有偏置，参数量仍然是 4*C*C。
Q/K/V 的投影均可读取全部 C 个输入通道；我们拆分的是投影后的输出通道。

例如 C=12、H=3，每个头拿到投影后连续的 4 个通道。每个头有自己的 Q/K/V 特征，
因此一般会产生不同的注意力矩阵。

每个头计算：

    A_h = softmax(Q_h K_hᵀ / sqrt(D) + causal_mask)   # (B,T,T)
    O_h = A_h V_h                                    # (B,T,D)
    output = concat(O_0, ..., O_(H-1)) @ Wo.T          # (B,T,C)

缩放除以 sqrt(D)，因为每次点积只累加 D 项。合头是拼接特征，不是求平均。
Wo 在合头后混合不同头提供的信息。

## 本关要掌握的轴操作

| 阶段 | 形状 | 含义 |
|---|---|---|
| 输入 / Q、K、V 投影 | (B,T,C) | 每个位置 C 个特征 |
| 特征拆成 H 组 | (B,T,H,D) | 每组 D 个特征 |
| 把头轴移到时间轴前 | (B,H,T,D) | 每个头有自己的完整序列 |
| 暂时把每个头当作独立样本 | (B*H,T,D) | 可调用第五讲的函数 |
| 每头注意力的输出 | (B*H,T,D) | 仍保持各头分离 |
| 恢复头轴 | (B,H,T,D) | 为合头做准备 |
| 合头 | (B,T,C) | 每个位置拼接各头的结果 |

`reshape` 按张量的逻辑元素顺序重新分组；`transpose` 交换两个轴。
它们做的事情不同。不能把 (B,T,C) 直接 reshape 成 (B,H,T,D)，就认为头和时间已正确排列。

用一个整数编号例子检查自己的理解：输入形状 (1,2,4)，两行分别为
`[0,1,2,3]` 和 `[4,5,6,7]`。H=2 时：

    头 0 的两个位置：[0,1]、[4,5]
    头 1 的两个位置：[2,3]、[6,7]

`transpose` 的结果通常不连续：逻辑轴已交换，但底层存储未必重排。
本题允许用 `reshape`，它会在需要时复制数据；也可先 `contiguous()` 再 `view()`。
这些操作都可以保留计算图；不要通过 `torch.tensor(已有张量)` 重建数据。

## 你要实现的接口

编辑 `src/l06a_multihead.py`，完成三个接口：

1. `split_heads(x, n_heads)`：`(B,T,C) -> (B,H,T,D)`。
   要满足 `out[b,h,t,j] == x[b,t,h*D+j]`；H 不为正或不能整除 C 时抛 `ValueError`。
2. `merge_heads(x)`：`(B,H,T,D) -> (B,T,H*D)`，严格逆转上述映射。
3. `MultiHeadAttention(d_model, n_heads)`：四个无偏置的线性层，属性名为
   `Wq/Wk/Wv/Wo`，另存 `n_heads` 与 `head_dim`。
   构造时 C/H 不为正或不能整除时抛 `ValueError`。
   `forward(x)` 输入输出都是 `(B,T,C)`。

本关输入 B、T、C 均为正整数，头数为整数。有效张量为浮点型，模块和输入的 dtype/device 匹配。
不要求处理空序列、非整数配置或错误秩的张量。

要求：

- 前向使用这两个拆合函数，并复用第五讲的 `scaled_dot_product_attention`。
- 合并 B 与 H 后调用第五讲；每个头之间不互相注意。
- 不修改输入，不丢失梯度，支持不连续输入。
- 不写 for/while/推导式遍历头，不调用内置注意力或 softmax。
- 不加入位置编码、残差、归一化、dropout；这些不是当前接口的一部分。
