# 6B1：LayerNorm

本关只实现 LayerNorm。通过后再写 FFN 和残差块。

## 它在模型里解决什么问题

多层网络不断对特征做线性变换和加法，不同位置的特征均值和幅度可能相差很大。
LayerNorm 为每个 token 的特征向量重新调整中心和尺度，给下一层提供更可控的输入尺度，帮助优化。
它不保证训练一定成功，也不要求所有 token 的内容变得相同。

我们稍后采用的 Transformer 块会在注意力和 FFN 的输入处使用 LayerNorm。
注意力在不同 token 之间传递信息；本关的归一化只在一个 token 内部计算。

## 数学定义

输入 x 的形状为 (B,T,C)。固定一个样本 b、一个位置 t，只看这个位置的 C 个数。

    mu = (x_0 + ... + x_(C-1)) / C
    var = ((x_0-mu)^2 + ... + (x_(C-1)-mu)^2) / C
    z_c = (x_c - mu) / sqrt(var + eps)
    y_c = gamma_c * z_c + beta_c

依次做四件事：求平均值；求与平均值的平方偏差的平均值；减均值并除以尺度；做可训练的逐通道缩放和平移。

例如 x=[1,3]，mu=2，var=1，忽略很小的 eps 后 z=[-1,1]。
另一个 token 若是 [10,14]，使用它自己的 mu=12、var=4，也得到约 [-1,1]。
这里没有把两个 token 的数放在一起求均值。

eps 默认是 1e-5，是固定的小常数，不参与训练。若所有通道相等，var=0，
它可以避免除以 0。注意 eps 放在平方根里面：sqrt(var+eps)。

因为有 eps，z 的方差是 var/(var+eps)，一般不是精确的 1。
经过可训练的 gamma、beta 之后，y 更不要求均值为 0 或方差为 1。

## 两个新的可训练参数

gamma 和 beta 的形状都是 (C,)，在所有样本、位置上共享。
它们分别对应代码中的属性 `weight` 和 `bias`。总参数量是 2*C。

gamma 初始化为 1，beta 初始化为 0。这样初始输出就是 z，之后模型可以学习各通道适合的幅度与偏移。
gamma/beta 是逐元素乘加，不是 C×C 的线性层。

你以前用 nn.Linear 时，层已经替你注册了参数。现在要自己做这件事：

    nn.Parameter(一个浮点 Tensor)

把得到的 Parameter 赋给模块属性，它就会被 `model.parameters()` 找到，优化器才能更新它。
普通 Tensor 即使设置 requires_grad=True，也不会因此自动进入模块的参数列表。
创建参数应放在 __init__；不要在 forward 中每次重新创建。

## 从公式对应到形状

| 对象 | 形状 | 作用 |
|---|---|---|
| x | (B,T,C) | 每个 token 的特征 |
| mu、var | (B,T,1) | 每个 token 各有一个统计量 |
| z、y | (B,T,C) | 保留原形状 |
| gamma、beta | (C,) | 广播到所有样本和位置 |

沿最后一维求 mean，配合 keepdim 保留长度为 1 的轴，就能与 x 广播。
方差可以直接按“平方偏差的平均值”写。不要误用除以 C-1 的样本方差：
这里是在归一化当前向量，题目定义明确除以 C。如果使用 torch.var，需明确 correction=0。

## 接口与任务范围

实现 `src/l06b1_layernorm.py` 中的：

    LayerNorm(d_model: int, eps: float = 1e-5)
    forward(x: Tensor) -> Tensor

输入为 (B,T,C)，B/T/C 均为正整数，C=d_model。输入和模块 dtype/device 匹配。
本关测试 float32/float64；不要求混合精度、空张量或错误秩的输入。
构造参数 d_model 必须为正整数（测试只传整数），eps 必须为正数（测试只传有限数），否则抛 ValueError。

必须注册名为 weight/bias 的两个 nn.Parameter，保存 eps；
不修改输入，支持非连续张量、C=1、全常量特征，保留所有梯度。
train() 与 eval() 应使用相同的当前输入统计量，不维护历史均值/方差。
不调用现成归一化，不写循环，用基础张量运算实现。
