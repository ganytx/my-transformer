# 默认训练数据：20000 段完整对话

从已下载的官方 smol-smoltalk 训练集抽样：**20000 段用于训练，另留 1000 段验证**；没有使用官方测试集来选样。固定版本、过滤数量和各文件 SHA-256 见 `manifest.json`。

训练集含 89,643 条消息、73,518,129 字符；验证集含 4,560 条消息、3,765,716 字符。训练词表为 97 个字符。最长训练对话为 63,937 字符，完整保留在数据中；256 字符的窗口只能看到其中一小部分。

抽样前保留完整的 system/user/assistant 消息及多轮历史，统一常见排版标点与换行；排除空内容、不支持的角色、非 ASCII 内容和控制字符。根据规范化后的首个用户消息去重，再用 seed=42 做蓄水池均匀抽样，并打乱后划分训练/验证。不是把同一批短样本重复扩充到 20000 条，没有长度筛选或答案截断。

- `train.txt` / `validation.txt`：完整角色文本，供当前 `play7.py` 读取。支持多行正文，角色依次为 `System:`、`User:`、`Assistant:`。
- `train.jsonl` / `validation.jsonl`：每行一段完整对话，字段 `messages`、`source`、`source_id`；用于追溯和后续扩展。它们不是当前 `finetune_chat.py` 要求的单行 user/assistant 问答格式，不要直接传给该脚本。

**256 字符是模型每次训练取出的窗口长度，不是每段对话的长度。** 当前训练循环随机抽取窗口，窗口可能从回答中途开始，也可能覆盖对话边界；长距离的问题与回答未必在同一窗口内。此处保留完整数据供后续改进窗口采样，而不是删除多轮内容。

在项目根目录运行 `python play7.py` 即使用本目录和下列默认参数：

```text
--device cuda --d-model 256 --layers 8 --heads 8 --context 256
--batch-size 64 --lr 0.0003 --steps 8000 --seed 42 --new-tokens 160
```

参数可照常覆盖。例如 `python play7.py --batch-size 8` 会降低一次训练的 batch，其他默认值保持不变。RTX 2060 6 GB 在原始注意力实现、float32、batch=64 下可能显存不足；本次没有自动试训或自动降低参数。

`python play7.py --data 其他文件.txt` 会恢复该文件前90%/后10%的简单划分，除非同时显式提供 `--val-data`。当前保存的是推理权重，每次重新运行都会重新初始化模型，不是断点续训。

复现：项目根目录 `python prepare_smoltalk_20k.py`，从已有 `full/train.jsonl` 重新生成本目录，不下载、不训练。原始全量和旧的 short_512 版均保留。
